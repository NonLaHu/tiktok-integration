TikTok Integration

A private tool that connects its owner's own TikTok account to a program on the owner's computer.

What this is

This website is the public home of a personal TikTok integration. It provides the terms, privacy policy, and login callback page that TikTok asks for. The tool itself runs only on the owner's computer.

What it does

  • Connects the owner's own TikTok account with TikTok Login Kit.
  • Reads the owner's basic profile and the owner's own video list.
  • Uploads videos that the owner chooses to the owner's own account.

Who can use it

Only the owner. It is not a public service and it does not access other people's data.
