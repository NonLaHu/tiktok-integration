# TikTok Integration

A private, personal integration for the owner's own TikTok account.

- Authorizes the owner's account with TikTok Login Kit (OAuth 2.0).
- Reads the owner's basic profile and the owner's own video list.
- Uploads videos created by the owner to the owner's own account.

This is not a public service and is not offered to third parties. No other users' data is accessed or collected.

Tokens are stored locally on the owner's machine. The only external API used is TikTok's official API. Not affiliated with TikTok.
