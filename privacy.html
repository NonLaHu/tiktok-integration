Privacy Policy

Effective date: November 17, 2026

1. Summary

This integration is a personal tool used only by the account owner. It does not collect data from third parties, does not use analytics or advertising, and does not run a public server that stores user data.

2. Data accessed

With the owner's authorization through TikTok Login Kit, the integration may access:

  • OAuth access and refresh tokens issued by TikTok for the owner's account.
  • The owner's basic profile information (such as display name, avatar, and open ID).
  • The list of videos on the owner's own TikTok account.
  • Video files that the owner chooses to upload to the owner's own account.

No data belonging to other TikTok users is accessed, collected, or processed.

3. How data is stored

OAuth tokens are stored locally on the owner's own machine in a local configuration file with restricted permissions. Profile data and video metadata are processed locally and are not uploaded to any server controlled by the operator. Video files are sent only to TikTok's official API endpoints when the owner initiates an upload.

4. Sharing

Data is not sold, rented, or shared with third parties. The integration does not use third-party analytics, tracking pixels, or advertising SDKs. The only external service it communicates with is TikTok's official API.

5. Retention

OAuth tokens are retained locally until they are revoked or deleted by the owner. Video files and metadata are not retained beyond the operation requested by the owner. Local logs do not contain typed text or credentials.

6. Security and revocation

Tokens are stored with restricted file permissions. The owner can revoke the integration's access at any time from TikTok's account settings, and can delete local token files from the owner's machine.

7. Children

This integration is not directed to children and is not intended for use by anyone other than the account owner.

8. Changes

This policy may be updated from time to time. The effective date above will be revised when changes are made.

9. Contact

Privacy questions can be raised through the repository's issue tracker: github.com/NonLaHu/tiktok-integration/issues.
